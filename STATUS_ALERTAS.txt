🚀 COMEÇAR AGORA
═══════════════════════════════════════════════════════════════════════════════

PASSO 1: Instalar Dependências (já feito)
   
   ✅ python-telegram-bot==20.7 instalado
   ✅ pytest instalado para testes

PASSO 2: Configurar Token Telegram

   Option A - Via Dashboard (Recomendado):
   
      1. streamlit run dashboard.py
      2. Lado esquerdo → 🔔 ALERTAS TELEGRAM → ⚙️ Configurar
      3. Expanda "🤖 Token do Telegram"
      4. Cole seu token: 8775070167:AAGjAIkwPsyVpw1TyaYDkQVrzk7-IaiFIpw
      5. Clique "✅ Validar Token" 
      6. Clique "💾 Salvar Token"
   
   Option B - Manual:
   
      1. Abra config/alertas_config.json
      2. Substitua "SEU_TOKEN_AQUI" por seu token
      3. Salve o arquivo

PASSO 3: Obter Chat ID

   1. Abra Telegram
   2. Inicie conversa com seu bot (@seu_bot_name)
   3. Envie qualquer mensagem
   4. Acesse: https://api.telegram.org/bot[TOKEN]/getUpdates
      (Substitua [TOKEN] por seu token)
   5. Procure "id" em "chat" → copie esse número
   
   ✅ Este será seu CHAT_ID (ex: -123456789)

PASSO 4: Criar Primeiro Alerta

   Via Dashboard:
   
      1. Dashboard → 🔔 ALERTAS TELEGRAM → ⚙️ Configurar
      2. Preencha "2️⃣ Novo Alerta":
         - Nome: "Teste SP"
         - Chat ID: [seu chat_id]
         - Estados: SP
         - Valores: 0 - 1000000
         - Clique "➕ Criar Alerta"
      3. Marque "Enviar alerta de teste?"
      4. 🔔 Receba mensagem no Telegram!

PASSO 5: Testar Monitor Automático

   1. Abra PowerShell/Terminal
   2. cd c:\licitacoes_pncp
   3. python monitor_alertas.py
   4. Se houver novas licitações, receberá alertas! 📬
