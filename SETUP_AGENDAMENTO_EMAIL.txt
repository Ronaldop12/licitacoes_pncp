🚀 PRÓXIMOS PASSOS - SETUP COMPLETO EM 5 MINUTOS
════════════════════════════════════════════════════════════════════════════════

PASSO 1: Gerar Senha de Aplicativo (2 min)
═══════════════════════════════════════════

Abra seu navegador:
   https://myaccount.google.com/apppasswords

👉 Clique em:
   1. "Segurança" (esquerda)
   2. Role para "App passwords"
   3. Selecione: Mail + Windows
   4. Clique "Gerar"
   5. COPIE a senha de 16 caracteres

✅ Exemplo: jxyz abcd efgh ijkl (com ou sem espaços)


PASSO 2: Executar Script de Agendamento (3 min)
════════════════════════════════════════════════

Abra PowerShell COMO ADMINISTRADOR:

   1. Clique com botão direito em PowerShell
   2. Escolha "Executar como administrador"
   3. Cole esse comando:

      cd c:\licitacoes_pncp
      .\configurar_agendamento.ps1

4. Siga as instruções:
   ├─ Alterar horário? (Digite S para 07:00 OU S + novo horário)
   └─ Ativar Email? (Digite S)
      ├─ Cole seu email: seu_email@gmail.com
      ├─ Cole a senha gerada: jxyzabcdefghijkl
      └─ Email destinatário? (ou deixe em branco para usar o mesmo)

✅ Pronto! Tarefa criada!


PASSO 3: Verificar se Funcionou (0 min)
═══════════════════════════════════════

Abra Agendador de Tarefas:
   1. Pressione WIN + R
   2. Digite: taskschd.msc
   3. Pressione ENTER

Na árvore esquerda procure:
   📁 Biblioteca de Tarefas
      └─ 📁 PNCP
         └─ ✅ PNCP_Alertas_Diario

Se aparecer aqui = SUCESSO! 🎉

Clique com botão direito > "Executar" para testar agora

🔍 TROUBLESHOOTING RÁPIDO
════════════════════════════════════════════════════════════════════════════════

PROBLEMA: "Erro de senha de app"
SOLUÇÃO:
  1. Volte em https://myaccount.google.com/apppasswords
  2. Gere uma NOVA e copie sem espaços
  3. Cole em config/alertas_config.json novamente

PROBLEMA: Agendador error ao executar
SOLUÇÃO:
  1. Clique em "Histórico" na tarefa para ver erro
  2. Verifique logs em: logs/monitor_alertas.log
  3. Execute manualmente: python monitor_alertas.py (para debug)

PROBLEMA: Email não chega
SOLUÇÃO:
  1. Confira config/alertas_config.json
  2. "email_config": { "ativo": true } ?
  3. Rode: python -c "from utils_email import EmailAlerter; ..."
  4. Se conectar = OK, procure por "Error" nos logs
